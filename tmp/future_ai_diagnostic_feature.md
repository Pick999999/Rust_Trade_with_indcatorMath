# แผนการพัฒนาฟีเจอร์ Self-Diagnostic & Post-Trade Analysis

เอกสารนี้รวบรวมแนวทางและไอเดียสำหรับการพัฒนาบอทในอนาคต เพื่อให้ระบบสามารถวิเคราะห์หาสาเหตุการชนะ/แพ้ (Win/Loss) ของแต่ละกลยุทธ์ได้อย่างชาญฉลาด โดยนำข้อมูลจาก `FullAnalysisResult` เข้ามาประเมินร่วมด้วย

---

## 🎯 เป้าหมายของฟีเจอร์
เปลี่ยนจากบอทที่เทรดตามสูตรตายตัวและบันทึกแค่ "Win/Loss" ไปเป็น **"ระบบที่สามารถวินิจฉัยความผิดพลาดของตัวเองได้"**
โดยจะสามารถบอกได้ว่า:
1. ทำไมกลยุทธ์นี้ถึงเลือกซื้อ Action นี้ (เหตุผล/กฎข้อไหนที่ถูกใช้งาน)
2. ถ้าแพ้... แพ้เพราะเหตุผลอะไรในเชิงเทคนิค (เช่น โดนหลอกด้วย ATR Spike หรือ RSI ผิดปกติ)
3. กลยุทธ์แต่ละตัวมีจุดบอดในสภาพตลาดแบบไหน เพื่อนำไปวิเคราะห์ต่อในอนาคต

---

## 🛠️ โครงสร้างที่ต้องปรับปรุง (Implementation Plan)

### 1. ปรับปรุงการส่งค่าคืนจาก `get_action.rs`
ปัจจุบันฟังก์ชันกลยุทธ์คืนค่าแค่คำว่า `"green"` หรือ `"red"` เราต้องเปลี่ยนให้มันคืนค่าข้อมูลที่ลึกขึ้น:

```rust
// ตัวอย่าง Struct ใหม่สำหรับคืนค่า
#[derive(Debug, Clone, Serialize)]
pub struct StrategyDecision {
    pub suggest_color: String,        // สีที่แนะนำ ("green" หรือ "red")
    pub reason: String,               // เหตุผลสั้นๆ เช่น "Loss_Con >= 2 และ EMA Short ชี้ลง"
    pub conditions_matched: Vec<String>, // เงื่อนไขย่อยที่เข้าเป้า เช่น ["ATR > 0.05", "RSI < 30"]
}
```

### 3. บันทึกข้อมูลลง `strategy_comparison.json`
ปรับปรุง JSON Object ตอนที่ Trade ปิด (ใน `deriv.rs`) ให้เพิ่มฟิลด์ที่เกี่ยวกับการวิเคราะห์เหตุผลลงไปด้วย

```json
{
    "activeStrategy": "V3A",
    "actualContractType": "CALL",
    "actualNextColor": "red",
    "actualProfit": -1.0,
    "assetCode": "R_75",
    
    // ข้อมูลส่วนวิเคราะห์เชิงลึก
    "v3a_reasoning": "เลือก CALL เพราะ Loss_Con < 2 (เข้าเงื่อนไข Default เล่นตามเทรนด์)",
    "v3a_loss_factor": "ความผันผวนผิดปกติ (ATR Spike สวนทางกระทันหันในวินาทีสุดท้าย)",
    "v1_reasoning": "เลือก PUT เพราะเล่นสวนสีแท่งก่อนหน้า",
    
    "winStatusByV3A": "Loss"
}
```

### 4. การแสดงผลในหน้าเว็บ (Frontend UI)
ปรับปรุงไฟล์ `index.html` เพื่อนำข้อมูลวิเคราะห์เชิงลึกไปแสดงผล:
* เพิ่มไอคอนแว่นขยาย (🔍) หรือปุ่ม "Analyze" ท้ายแถวแต่ละไม้
* เมื่อคลิกปุ่ม จะแสดง Popup (Modal) โชว์สรุปเลยว่า:
  * **V3A ตัดสินใจจากอะไร:** ...
  * **ทำไมถึงแพ้:** ...
  * **สภาพตลาดตอนนั้น:** ATR = ..., RSI = ...

## 🚀 ลำดับการทำ (ถ้าเริ่มทำในอนาคต)
1. เริ่มแก้ Struct ใน `get_action.rs` ให้รองรับการส่งค่ากลับหลายอย่าง
2. ตามไปแก้โค้ดใน `deriv.rs` ทุกจุดที่เรียกใช้ `get_suggest_color_by_strategy` ให้รับ Struct ใหม่
3. เพิ่มข้อมูลลงใน Log ของ `pending_strategy_entry`
4. รันเก็บข้อมูลสัก 1 วัน ให้มีข้อมูลดิบที่มี Reasoning ก่อน
5. สร้าง UI ใน `index.html` เพื่อดึง JSON เหล่านี้มาแสดงเป็นหน้าต่าง Diagnostic สวยๆ
