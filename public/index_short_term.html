🔍 Post-Trade Diagnostic

📖 รหัสเงื่อนไข (Condition Codes)

อธิบายรหัสเงื่อนไขการตัดสินใจ (Condition Codes) ของแต่ละกลยุทธ์ที่ใช้ในระบบเทรด ซึ่งรหัสเหล่านี้จะถูกบันทึกลงในฟิลด์ codeStrategy ของไฟล์ trades.json เมื่อจบไม้แต่ละไม้

กลยุทธ์ V1 (ดั้งเดิม)

  • V1-A : เข้าเงื่อนไข Default (lossCon < 2) → แนะนำ Green
  • V1-B : เข้าเงื่อนไข lossCon >= 2 และแท่งเทียนปัจจุบันสีเขียว → แนะนำ Green
  • V1-C : เข้าเงื่อนไข lossCon >= 2 และแท่งเทียนปัจจุบันสีแดง → แนะนำ Red

กลยุทธ์ V2 (Early React)

  • V2-A : เข้าเงื่อนไข Default (lossCon < 1) → แนะนำ Green
  • V2-B : เข้าเงื่อนไข lossCon >= 1 และแท่งเทียนปัจจุบันสีเขียว → แนะนำ Green
  • V2-C : เข้าเงื่อนไข lossCon >= 1 และแท่งเทียนปัจจุบันสีแดง → แนะนำ Red

กลยุทธ์ V3A (EMA Consensus)

  • V3A-A : เข้าเงื่อนไข Default (lossCon < 2) → แนะนำ Green
  • V3A-B : เข้าเงื่อนไข lossCon >= 2 และเสียงส่วนใหญ่ของ 3 EMA ชี้ขึ้น (Majority Up) → แนะนำ Green
  • V3A-C : เข้าเงื่อนไข lossCon >= 2 และเสียงส่วนใหญ่ของ 3 EMA ชี้ลง (Majority Down) → แนะนำ Red

กลยุทธ์ V3B (EMA Short + CutType)

  • V3B-A : เข้าเงื่อนไข Default (lossCon < 2) → แนะนำ Green
  • V3B-B : เข้าเงื่อนไข lossCon >= 2 และเส้น EMA Short ชี้ขึ้น → แนะนำ Green
  • V3B-C : เข้าเงื่อนไข lossCon >= 2 และเส้น EMA Short ชี้ลง → แนะนำ Red
  • V3B-D : เข้าเงื่อนไข lossCon >= 2 เกิดการตัดขึ้น (CutUp Override) → แนะนำ Green
  • V3B-E : เข้าเงื่อนไข lossCon >= 2 เกิดการตัดลง (CutDown Override) → แนะนำ Red

กลยุทธ์ FTA (2 EMA Direction)

  • FTA-A : EMA Short และ Medium ชี้ขึ้นเหมือนกัน → แนะนำ Green
  • FTA-B : EMA Short และ Medium ชี้ลงเหมือนกัน → แนะนำ Red
  • FTA-C : ทิศทาง EMA Short ไม่ตรงกับ Medium → แนะนำ Idle (ข้ามไม้)

กลยุทธ์ FTB (3 EMA Direction)

  • FTB-A : EMA Short, Medium, Long ชี้ขึ้นเหมือนกันหมด → แนะนำ Green
  • FTB-B : EMA Short, Medium, Long ชี้ลงเหมือนกันหมด → แนะนำ Red
  • FTB-C : ทิศทาง EMA ทั้ง 3 เส้นไม่สอดคล้องกัน → แนะนำ Idle (ข้ามไม้)

กลยุทธ์ PKTrend (PK Trend Spot Evaluator V1)

  • PKT-UP-CONFIRM / PKT-SPK-CONTINUE-UP : UpTrend แข็งแกร่ง + Close Conviction ด้านบน → แนะนำ Green (CALL)
  • PKT-DN-CONFIRM / PKT-SPK-CONTINUE-DN : DownTrend แข็งแกร่ง + Close Conviction ด้านล่าง → แนะนำ Red (PUT)
  • PKT-RJ-BEARTRAP-STRONG : Bear Trap ยืนยันในโซน Rejected → Reversal แนะนำ Green (CALL)
  • PKT-RJ-BULLTRAP-STRONG : Bull Trap ยืนยันในโซน Rejected → Reversal แนะนำ Red (PUT)
  • PKT-WAIT : ติด Safety Filters (Whipsaw, Sideways, Dangerous Spike Trap) หรือคะแนนไม่ถึงเกณฑ์ → แนะนำ Idle (ข้ามไม้)

กลยุทธ์ PKTrend V5 (27 Price Action Patterns & Structure)

  • PKT5-UP-CONFIRM / PKT5-EG-BULLISH : แท่งเทียนขาขึ้นสมบูรณ์ + HH/HL + Score ≥ 30 → แนะนำ Green (CALL)
  • PKT5-DN-CONFIRM / PKT5-EG-BEARISH : แท่งเทียนขาลงสมบูรณ์ + LL/LH + Score ≤ -30 → แนะนำ Red (PUT)
  • PKT5-RJ-BEARTRAP-STRONG : หลุด Low แล้วดึงกลับปิดบน (Bear Trap Rejection) → แนะนำ Green (CALL)
  • PKT5-RJ-BULLTRAP-STRONG : ทะลุ High แล้วทุบกลับปิดล่าง (Bull Trap Rejection) → แนะนำ Red (PUT)
  • PKT5-WHIPSAW-BLOCK : สลับสี 4 แท่งติดต่อกัน (Confirmed Whipsaw Zone) → บล็อกการเทรด แนะนำ Idle

กลยุทธ์ Forecast Sequence (2-Bar Sequence Action คู่รหัสแท่ง)

  • FC-CALL-UP-CONFIRM : แท่งก่อนหน้าส่งโมเมนตัมขึ้นต่อ (Momentum Continuation) → แนะนำ Green (CALL)
  • FC-PUT-DN-CONFIRM : แท่งก่อนหน้าส่งโมเมนตัมลงต่อ (Momentum Continuation) → แนะนำ Red (PUT)
  • FC-PUT-BULLTRAP (คู่รหัส 1➔11, 25➔11) : Bull Trap พลิกผัน → สับสัญญาณเปิด PUT สวนทันที
  • FC-CALL-BEARTRAP (คู่รหัส 2➔12, 25➔12) : Bear Trap พลิกผัน → สับสัญญาณเปิด CALL สวนทันที
  • FC-WAIT : ไร้คู่รหัสหรือความมั่นใจต่ำ (Low Confidence) → แนะนำ Idle
