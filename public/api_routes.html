🚀 API Routes Documentation

PK Deriv Trade - Backend API Reference

📊 Short Term Trade

POST /api/trade
เริ่มต้น Short Term Trading bot
Body: { "assets": ["vol10", "vol50"], "strategy": "ATRSpike", ... }
POST /api/stop
หยุด Short Term Trading bot
POST /api/manual_trade
เปิด Order แบบ Manual (Short Term)
Body: { "asset": "vol10", "contract_type": "CALL", "amount": 1 }
POST /api/sell
ขาย Order ก่อนหมดเวลา (Short Term)
Body: { "contract_id": 123456789 }
GET /api/setup
ดึงการตั้งค่า Short Term Trade
POST /api/setup
บันทึกการตั้งค่า Short Term Trade
GET /api/settings
ดึงการตั้งค่าระบบ settings.json (Sync Dashboard)
POST /api/settings
บันทึกการตั้งค่าระบบ settings.json (Sync Dashboard)
GET /api/tradeControl
ดึงข้อมูล Trade Control (Short Term)

📈 Long Term Trade

POST /api/longterm/start
เริ่มต้น Long Term Trading bot
Body: { "assets": ["vol10"], "granularity": 60 }
POST /api/longterm/stop
หยุด Long Term Trading bot
POST /api/longterm/toggle_auto
เปิด/ปิด Auto Trade (Long Term)
Body: { "enabled": true }
POST /api/longterm/manual_trade
เปิด Order แบบ Manual (Long Term)
Body: { "asset": "vol10", "contract_type": "CALL", "amount": 1, "target_profit": 10, "exit_strategy": "targetProfit" }
POST /api/longterm/sell
ขาย Order (Long Term)
Body: { "contract_id": 123456789 }
POST /api/longterm/target
เปลี่ยน Target Profit ของ Order ที่กำลังเปิดอยู่
Body: { "contract_id": 123456789, "new_target": 15 }
GET /api/longterm/candles
ดึงข้อมูล Candles สำหรับกราฟ Long Term
?asset=vol10&granularity=60&count=300
GET /api/longterm/settings
ดึงการตั้งค่า Long Term Trade
POST /api/longterm/settings
บันทึกการตั้งค่า Long Term Trade
GET /api/longterm/active-settings
ดึงการตั้งค่าที่กำลังใช้งานอยู่ (Active Settings)
GET /api/longterm/schedule
ดึงการตั้งค่า Schedule (Long Term)
POST /api/longterm/schedule
บันทึกการตั้งค่า Schedule (Long Term)
POST /api/longterm/save_track_snapshot
บันทึก Track Order Snapshot (1 รายการ)
POST /api/longterm/save_track_snapshots_batch
บันทึก Track Order Snapshots (หลายรายการพร้อมกัน)

📁 Data & History

GET /api/getTradeHistory
ดึงข้อมูล Trade History จากไฟล์ trades.json
?day_trade=2026-08-18&asset=1HZ10V
GET /api/availableTradeData
ดึงรายการ Trade Data ทั้งหมดที่มีในระบบ (สแกนโฟลเดอร์ tradeData)
GET /api/export_trade_data
Export Trade Data เป็นไฟล์ ZIP
?startdatetime=2026-08-01
GET /api/getStrategyComparison
ดึงข้อมูลเปรียบเทียบกลยุทธ์
?day_trade=2026-08-18
GET /api/history
ดึงข้อมูล Manual Trade History
POST /api/save_manual_history
บันทึก Manual Trade History
POST /api/generate_analysis
สร้างไฟล์วิเคราะห์ (Analysis) จาก Candles
GET /getanalysisdata
ดึงข้อมูล Analysis Data
GET /getFullAnalysisData
ดึงข้อมูล Full Analysis Data (รวมข้อมูลทั้งหมด)
POST /getAnalysisdata
ดึงข้อมูล Analysis Data (POST version)

⚙️ System & Configuration

GET /api/status
ดึงสถานะระบบ (bot_count, active_assets, balance, is_trading, etc.)
GET /api/version
ดึงเวอร์ชันของ Backend
POST /api/terminate
ปิดโปรแกรม Backend ทั้งหมด
POST /api/notify
ส่ง Notification (Telegram)
POST /api/balance/sync
ซิงค์ยอดเงิน (Balance) จาก Deriv
GET /api/deriv-config
ดึงการตั้งค่า Deriv API
GET /api/deriv-otp
ดึง OTP Code สำหรับ Deriv 2FA
POST /api/longterm/reconnect_ws
Reconnect WebSocket (Long Term)
GET /api/config/url_ajax_post
ดึง URL สำหรับ AJAX POST
GET /api/thereshold
ดึงการตั้งค่า Threshold
POST /api/thereshold
บันทึกการตั้งค่า Threshold
POST /api/verify_fingerprint
ตรวจสอบ Fingerprint (Authentication)

🔌 WebSocket & Static Files

GET /ws
WebSocket Connection Endpoint (Real-time communication)
ws://localhost:3000/ws?token=YOUR_API_KEY
GET /tradeData/**
Static file serving สำหรับโฟลเดอร์ tradeData
/tradeData/08-2569/18-08-2569/1HZ10V/trades.json
GET /sounds/**
Static file serving สำหรับไฟล์เสียง
