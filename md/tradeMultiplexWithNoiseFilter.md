# สรุปฟีเจอร์ tradeMultiplexWithNoiseFilter

ฟีเจอร์ **Noise Filter** ในโปรเจกต์เวอร์ชันนี้ถูกออกแบบมาเพื่อแก้ปัญหา **Loss Streak** (การเทรดเสียติดๆ กัน) โดยเน้นไปที่การกรองจังหวะที่กราฟผันผวน กราฟพักตัว หรือตลาดไม่มีเทรนด์ ไม่ให้บอทเข้าเทรด

## 1. ฟีเจอร์ตัวกรองใหม่ที่เพิ่มเข้ามา
มีการเพิ่มตัวกรองหลัก 4 รูปแบบในการหลีกเลี่ยงสภาวะตลาดที่ไม่เหมาะสม:
- **ADX Filter (กรองตลาดไม่มีเทรนด์):** บล็อกการเทรดหากค่า ADX ต่ำกว่าที่กำหนด (เช่น ต่ำกว่า 25) ถือว่าแรงเหวี่ยงหรือเทรนด์อ่อนแอเกินไป
- **Choppy Filter (กรองตลาด Sideway):** บล็อกการเทรดหากค่า Choppy Indicator สูงกว่าที่กำหนด (เช่น สูงกว่า 50) ถือว่าตลาดวิ่งออกข้าง
- **Range Filter (กรองกรอบราคา):** บล็อกการเทรดเมื่อราคากำลังสวิงไปมาอยู่ในกรอบแคบๆ (Range box) 
- **BB Squeeze Filter (กรองความผันผวนต่ำ):** บล็อกการเทรดหากระยะห่างของ Bollinger Bands (Bandwidth) แคบเกินไป แสดงถึงภาวะสะสมพลัง

*(หมายเหตุ: ยังมีตัวกรองเดิมทำงานร่วมด้วย เช่น กรองกราฟสลับสี, กรองช่วง EMA แบนราบ (EMA Flat), กรองช่องว่างระหว่าง EMA (Gap) เป็นต้น)*

## 2. วิธีการเปิดใช้งานบน Frontend UI
ฟีเจอร์ทั้งหมดได้ถูกเขียน logic ไว้ใน Backend (Rust) แล้ว โดยสามารถควบคุมการทำงานได้ผ่านหน้าเว็บ (UI):
1. ไปที่เมนู **"ตั้งค่า Threshold"** (รูป ⚙)
2. ดูในส่วนหมวดหมู่ **"🛡️ Noise Filters ใหม่ (ลด Loss Streak)"**
3. สามารถ "ติ๊กถูก" เปิด/ปิดใช้งานตัวกรองแต่ละตัว และตั้งค่าความไว (Threshold) ของแต่ละฟีเจอร์ได้โดยตรงผ่านหน้าเว็บ
4. เมื่อกดบันทึก ข้อมูลจะถูกเก็บลงไฟล์ `setup/thereshold.json` ซึ่งบอทจะอ่านและนำค่าเหล่านั้นไปใช้งานทันที

## 3. ความแตกต่างระหว่าง tradeMultiplex.service กับ tradeMultiplexWithNoiseFilter.service
จากการตรวจสอบเนื้อหาพบว่า **ไม่มีความแตกต่างกันเลย (เหมือนกัน 100%)**
- ทั้งคู่ใช้ `WorkingDirectory` และ `ExecStart` ชี้ไปที่ `/home/ubuntu/indicators_MultiplexWithNoiseFilter` เดียวกัน
- คาดว่าเป็นการ Copy ไฟล์แยกเผื่อไว้ แต่ถูกแก้ไขให้อ้างอิงถึงโฟลเดอร์เดียวกันในภายหลัง
- ดังนั้นไม่ว่าจะรันด้วย Service ใด ผลลัพธ์และการทำงานจะเหมือนกันทุกประการ (สามารถลบออกหนึ่งไฟล์เพื่อลดความสับสนได้)
