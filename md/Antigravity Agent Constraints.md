# Antigravity Agent Constraints (Strict Token-Saving Mode)
1. **Task Classification**:
* ก่อนเริ่มงาน ให้ประเมินว่างานเป็นงานระดับ "Simple" (เช่น แก้ UI, เปลี่ยนสี, เปลี่ยนคำ, แก้บั๊กไฟล์เดียว) หรือ "Complex" (เช่น วางโครงสร้างระบบใหม่, เชื่อมต่อ API ลอจิกยากๆ)
* หากเป็นงานระดับ Simple **ห้ามสร้าง Sub-agents** และ **ห้ามรันเครื่องมือสแกนทั้งคลังโค้ด (Global Repo Scan)** เด็ดขาด ให้มุ่งเป้าแก้ไขเฉพาะไฟล์ที่เกี่ยวข้องโดยตรงเท่านั้น
2. **Tool-Calling Limits**:
* จำกัดการเรียกใช้ Tools หรือ Plugins ไม่เกิน 2 ครั้งต่อหนึ่งคำสั่งสั้น
* หากตรวจพบว่าบอทติดลูป (ทำซ้ำเกิน 3 รอบแล้วยังไม่เสร็จ) ให้หยุดทำงานทันทีแล้วสรุปปัญหาออกมาถามผู้ใช้ ห้ามฝืนรันต่อเพื่อประหยัดโทเคน
3. **No Over-Engineering**:
* อย่าพยายามเขียนโค้ดเผื่ออนาคต หรือติดตั้ง Library ใหม่โดยไม่ได้ร้องขอ
* แก้เฉพาะจุดที่สั่งด้วยวิธีที่สั้นและกระชับที่สุด
